# 8th Street Stormwater Survey Map

Interactive field photo map built with Leaflet.js. Drop in a folder of GPS-tagged photos and the map places them automatically using EXIF coordinates.

---

## Before you start — create the GitHub repo first

**Do this before putting any files together.** Creating the repo on GitHub first gives you a clean place to clone from, so your local folder is already a proper git repo from day one.

1. Go to [github.com](https://github.com) and sign in
2. Click **New repository**
3. Name it (e.g. `example-survey-map`), set it to **Public**, check **Add a README file**, click **Create repository**
4. On the repo page click **Code → Copy the HTTPS URL** (looks like `https://github.com/your-username/your-repo.git`)
5. Open a terminal, navigate to where you want the project folder, and clone it:

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

Now copy `index.html` and the rest of the project files into this cloned folder. All your work happens here — it is already a git repo ready to push when you're done.

## Step 1 — Compress photos for the web

Run this PowerShell script once. It reads every JPG from `photos\` and writes a resized copy (1200 px max, quality 75) to `photos_web\`, mirroring the subfolder structure.

```powershell
Add-Type -AssemblyName System.Drawing

$src  = ".\photos"
$dst  = ".\photos_web"
$maxW = 1200
$qual = 75L

$jpegCodec = [System.Drawing.Imaging.ImageCodecInfo]::GetImageEncoders() |
             Where-Object { $_.MimeType -eq 'image/jpeg' } |
             Select-Object -First 1
$qualParam = New-Object System.Drawing.Imaging.EncoderParameters(1)
$qualParam.Param[0] = New-Object System.Drawing.Imaging.EncoderParameter(
    [System.Drawing.Imaging.Encoder]::Quality, $qual)

Get-ChildItem -Path $src -Recurse -Include *.jpg,*.jpeg,*.JPG,*.JPEG | ForEach-Object {
    $rel     = $_.FullName.Substring((Resolve-Path $src).Path.Length + 1)
    $outPath = Join-Path $dst $rel
    $outDir  = Split-Path $outPath
    if (-not (Test-Path $outDir)) { New-Item -ItemType Directory -Path $outDir | Out-Null }

    $img = [System.Drawing.Image]::FromFile($_.FullName)
    $scale = [Math]::Min(1.0, $maxW / [Math]::Max($img.Width, $img.Height))
    $newW  = [int]($img.Width  * $scale)
    $newH  = [int]($img.Height * $scale)

    $bmp = New-Object System.Drawing.Bitmap($newW, $newH)
    $g   = [System.Drawing.Graphics]::FromImage($bmp)
    $g.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
    $g.DrawImage($img, 0, 0, $newW, $newH)

    $bmp.Save($outPath, $jpegCodec, $qualParam)
    $g.Dispose(); $bmp.Dispose(); $img.Dispose()
    Write-Host "Compressed: $rel"
}
```

## Step 2 — Extract GPS from photos → photos.json

This script reads EXIF GPS data from every photo in `photos\` and writes `data\photos.json` — a GeoJSON FeatureCollection that the map loads.

```powershell
Add-Type -AssemblyName System.Drawing

function Get-RationalTriplet($bytes, $offset) {
    $vals = @()
    for ($i = 0; $i -lt 3; $i++) {
        $num = [BitConverter]::ToUInt32($bytes, $offset + $i*8)
        $den = [BitConverter]::ToUInt32($bytes, $offset + $i*8 + 4)
        $vals += if ($den -eq 0) { 0 } else { $num / $den }
    }
    $vals[0] + $vals[1]/60 + $vals[2]/3600
}

$photos  = Get-ChildItem ".\photos" -Recurse -Include *.jpg,*.jpeg,*.JPG,*.JPEG
$features = @()

foreach ($f in $photos) {
    try {
        $img   = [System.Drawing.Image]::FromFile($f.FullName)
        $props = @{}
        foreach ($p in $img.PropertyItems) { $props[$p.Id] = $p }
        $img.Dispose()

        if (-not ($props.ContainsKey(2) -and $props.ContainsKey(4))) { continue }

        $lat = Get-RationalTriplet $props[2].Value 0
        $lon = Get-RationalTriplet $props[4].Value 0
        if (([System.Text.Encoding]::ASCII.GetString($props[3].Value)).Trim("`0") -eq 'W') { $lon = -$lon }
        if (([System.Text.Encoding]::ASCII.GetString($props[1].Value)).Trim("`0") -eq 'S') { $lat = -$lat }

        $ts = ""
        if ($props.ContainsKey(36867)) {
            $ts = [System.Text.Encoding]::ASCII.GetString($props[36867].Value).Trim("`0")
        }

        # Build relative path from project root (forward slashes for web)
        $rel = $f.FullName.Substring((Resolve-Path ".\photos").Path.Length + 1) -replace '\\','/'

        $features += [PSCustomObject]@{
            type = "Feature"
            geometry = [PSCustomObject]@{ type = "Point"; coordinates = @($lon, $lat) }
            properties = [PSCustomObject]@{
                file      = "photos/$rel"
                timestamp = $ts
                caption   = ""
            }
        }
    } catch { Write-Warning "Skipped $($f.Name): $_" }
}

$geojson = [PSCustomObject]@{ type = "FeatureCollection"; features = $features }
$geojson | ConvertTo-Json -Depth 10 | Set-Content ".\data\photos.json" -Encoding utf8
Write-Host "$($features.Count) photos written to data\photos.json"
```

Photos without GPS data are silently skipped. After running, open `data\photos.json` and confirm coordinates look correct before serving the map.

## Step 3 — Customize index.html

There are four places to edit:

### 3a. Panel title and client

```html
<!-- Around line 590 in index.html -->
<h2>
  <div>
    <div class="panel-project">8th Street Corridor</div>   <!-- ← your project name -->
    <div class="panel-client">City of Oakland</div>        <!-- ← your client -->
    <div class="panel-preparedby">Prepared by Geronimo Engineering</div>
  </div>
  <button id="panel-close">&times;</button>
</h2>
```

### 3b. Map center and zoom

```javascript
// Find this line in the <script> block
.setView([37.800156, -122.272038], 16);
//         ↑ lat        ↑ lng       ↑ zoom (14=neighborhood, 16=block, 18=parcel)
```

### 3c. Photo layer label

```html
<!-- Single checkbox in the layers section -->
<label for="chk-photos">Field Photos (87)</label>
<!-- Change 87 to your actual photo count -->
```

### 3d. Highlighted Photos panel

Each card in `#highlights-list` follows this pattern:

```html
<div class="highlight-card">
  <div class="highlight-thumb"
       onclick="openLightbox('photos/survey_jan2026/IMG_0042.JPG', 'Caption — date')">
    <img src="highlights/IMG_0042.jpg" loading="lazy" alt="" />
    <button class="highlight-locate"
            onclick="event.stopPropagation(); map.flyTo([37.8001, -122.2720], 19)"
            title="Snap map to this location">
      <svg viewBox="0 0 24 24" fill="#D4891A">
        <path d="M12 2C8.13 2 5 5.13 5 9c0 5.25 7 13 7 13s7-7.75 7-13c0-3.87-3.13-7-7-7zm0 9.5c-1.38 0-2.5-1.12-2.5-2.5s1.12-2.5 2.5-2.5 2.5 1.12 2.5 2.5-1.12 2.5-2.5 2.5z"/>
      </svg>
    </button>
  </div>
  <div class="highlight-label">Location Name</div>
  <div class="highlight-desc">Optional description text here.</div>
</div>
```

- `openLightbox(...)` — path to the **original full-res** photo; caption shown below it
- `<img src="highlights/...">` — path to the **compressed** copy for fast loading
- `map.flyTo([lat, lng], 19)` — coordinates copied from `photos.json` for that image

Add or remove as many cards as needed. The panel scrolls automatically.

## Step 4 — Run locally first

**Do not push to GitHub yet.** Verify everything looks correct on your machine before making it public.

The map uses `fetch()` to load `photos.json`, so it won't work from `file://` — you need a local server:

```bash
# Python (no install needed)
python -m http.server 8080

# or Node
npx serve .
```

Open **http://localhost:8080** and check:
- All photo markers appear on the map at the correct locations
- Clicking a marker opens the correct photo in the lightbox
- Highlighted Photos panel shows the right images and the pin buttons fly to the right spots
- Title, client name, and map center look correct

Fix anything before moving to the next step.

## Step 5 — Commit and push to GitHub

Once the map looks right locally, save your work to the repo:

```bash
# From inside your cloned repo folder
git add .
git commit -m "Initial map build"
git push origin main
```

> **Large files:** `photos/` (full-res originals) can easily be hundreds of MB. If that's too large for GitHub (limit is 100 MB per file, 1 GB per repo), add the originals folder to `.gitignore` and only commit `photos_web/` and `highlights/`. Update `photos.json` paths to point at `photos_web/` instead — the lightbox will open the compressed version.
>
> ```
> # .gitignore
> photos/
> ```
