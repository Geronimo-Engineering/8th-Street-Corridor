# Geronimo Engineering — Field Survey Map

Interactive field photo map built with Leaflet.js. Drop in GPS-tagged photos and optional City of Oakland GIS layers; the map places everything automatically.

This README is written for a new agent or engineer setting up a fresh instance of this map for a new project area in Oakland.

---

## What this map does

- Places GPS-tagged field photos as clustered camera markers on a street or satellite basemap
- Highlighted Photos panel: curated cards each with a 35×35 mini-map thumbnail showing the exact location; clicking the mini-map flies the main map there with a 6-second amber pulse animation
- Optional infrastructure layers from the City of Oakland GIS Portal (storm drains ● and storm inlets ◆), pre-filtered to the project area
- Address / coordinate search, compass rotation, right-click to copy coordinates
- Fully responsive; mobile panel and highlights drawer slide in from edges

## Step 1 — Compress photos for the web

Run once. Reads every JPG from `photos\` and writes a resized copy (1200 px max, quality 75) to `photos_web\`, mirroring the subfolder structure.

```powershell
Add-Type -AssemblyName System.Drawing

$src  = ".\photos"
$dst  = ".\photos_web"
$maxW = 1200
$qual = 75L

$jpegCodec = [System.Drawing.Imaging.ImageCodecInfo]::GetImageEncoders() |
             Where-Object { $_.MimeType -eq 'image/jpeg' } |
             Select-Object -First 1
$qualParam = New-Object System.Drawing.Imaging.EncoderParameters(1)
$qualParam.Param[0] = New-Object System.Drawing.Imaging.EncoderParameter(
    [System.Drawing.Imaging.Encoder]::Quality, $qual)

Get-ChildItem -Path $src -Recurse -Include *.jpg,*.jpeg,*.JPG,*.JPEG | ForEach-Object {
    $rel     = $_.FullName.Substring((Resolve-Path $src).Path.Length + 1)
    $outPath = Join-Path $dst $rel
    $outDir  = Split-Path $outPath
    if (-not (Test-Path $outDir)) { New-Item -ItemType Directory -Path $outDir | Out-Null }

    $img = [System.Drawing.Image]::FromFile($_.FullName)
    $scale = [Math]::Min(1.0, $maxW / [Math]::Max($img.Width, $img.Height))
    $newW  = [int]($img.Width  * $scale)
    $newH  = [int]($img.Height * $scale)

    $bmp = New-Object System.Drawing.Bitmap($newW, $newH)
    $g   = [System.Drawing.Graphics]::FromImage($bmp)
    $g.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
    $g.DrawImage($img, 0, 0, $newW, $newH)

    $bmp.Save($outPath, $jpegCodec, $qualParam)
    $g.Dispose(); $bmp.Dispose(); $img.Dispose()
    Write-Host "Compressed: $rel"
}
```

## Step 2 — Extract GPS from photos → photos.json

Reads EXIF GPS data from every photo in `photos\` and writes `data\photos.json`. Photos without GPS are silently skipped.

Add a `caption` string to each feature after generating if you want location labels to appear in the lightbox.

```powershell
Add-Type -AssemblyName System.Drawing

function Get-RationalTriplet($bytes, $offset) {
    $vals = @()
    for ($i = 0; $i -lt 3; $i++) {
        $num = [BitConverter]::ToUInt32($bytes, $offset + $i*8)
        $den = [BitConverter]::ToUInt32($bytes, $offset + $i*8 + 4)
        $vals += if ($den -eq 0) { 0 } else { $num / $den }
    }
    $vals[0] + $vals[1]/60 + $vals[2]/3600
}

$photos   = Get-ChildItem ".\photos" -Recurse -Include *.jpg,*.jpeg,*.JPG,*.JPEG
$features = @()

foreach ($f in $photos) {
    try {
        $img   = [System.Drawing.Image]::FromFile($f.FullName)
        $props = @{}
        foreach ($p in $img.PropertyItems) { $props[$p.Id] = $p }
        $img.Dispose()

        if (-not ($props.ContainsKey(2) -and $props.ContainsKey(4))) { continue }

        $lat = Get-RationalTriplet $props[2].Value 0
        $lon = Get-RationalTriplet $props[4].Value 0
        if (([System.Text.Encoding]::ASCII.GetString($props[3].Value)).Trim("`0") -eq 'W') { $lon = -$lon }
        if (([System.Text.Encoding]::ASCII.GetString($props[1].Value)).Trim("`0") -eq 'S') { $lat = -$lat }

        $ts = ""
        if ($props.ContainsKey(36867)) {
            $ts = [System.Text.Encoding]::ASCII.GetString($props[36867].Value).Trim("`0")
        }

        $rel = $f.FullName.Substring((Resolve-Path ".\photos").Path.Length + 1) -replace '\\','/'

        $features += [PSCustomObject]@{
            type     = "Feature"
            geometry = [PSCustomObject]@{ type = "Point"; coordinates = @($lon, $lat) }
            properties = [PSCustomObject]@{
                file      = "photos/$rel"
                timestamp = $ts
                caption   = ""
                survey    = ""   # optional: tag e.g. "jan2026" to distinguish survey dates
            }
        }
    } catch { Write-Warning "Skipped $($f.Name): $_" }
}

$geojson = [PSCustomObject]@{ type = "FeatureCollection"; features = $features }
$geojson | ConvertTo-Json -Depth 10 | Set-Content ".\data\photos.json" -Encoding utf8
Write-Host "$($features.Count) photos written to data\photos.json"
```

After running, open `data\photos.json` and confirm coordinates look correct before serving the map.

### 3d. Highlighted Photos panel

Each card in `#highlights-list` looks like this:

```html
<div class="highlight-card">
  <div class="highlight-thumb"
       onclick="openLightbox('photos/survey_jan2026/IMG_0042.JPG', 'Location name — date')">
    <img src="photos_web/survey_jan2026/IMG_0042.jpg" loading="lazy" alt="" />
    <div class="highlight-minimap" data-lat="37.8001" data-lng="-122.2720"></div>
  </div>
  <div class="highlight-label">Location Name</div>
  <div class="highlight-desc">Optional description.</div>
</div>
```

- `openLightbox(path, caption)` — path to the **full-res** original; caption shown in lightbox
- `<img src="photos_web/...">` — path to the **compressed** copy for fast thumbnail loading
- `data-lat` / `data-lng` — copy the exact coordinates from `photos.json` for that image

The mini-map and click-to-fly behaviour are handled automatically by the JS. You only need to supply the coordinates as data attributes.

To find the right coordinates: open `data/photos.json`, locate the feature whose `file` matches your image, and copy `coordinates[1]` (lat) and `coordinates[0]` (lng).

## Step 4 — Add Oakland GIS infrastructure layers (optional)

Download CSV exports from the [City of Oakland GIS Portal](https://data.oaklandca.gov) (search for "storm drain" or "inlet"). Then run this script to filter to your project bounding box and convert to GeoJSON:

```powershell
# ── Set your project bounding box ────────────────────────────────────────────
$minLat = 37.790; $maxLat = 37.810   # ← adjust for your corridor
$minLng = -122.285; $maxLng = -122.255

# ── Storm Drains ─────────────────────────────────────────────────────────────
# Expected columns: OBJECTID_1, OBJECTID, STRUC_ID, LONG, LAT
$drains = Import-Csv "path\to\oakdrainsgeo.csv"
$drainsFeatures = $drains | Where-Object {
    [double]$_.LAT -ge $minLat -and [double]$_.LAT -le $maxLat -and
    [double]$_.LONG -ge $minLng -and [double]$_.LONG -le $maxLng
} | ForEach-Object {
    $lat = [double]$_.LAT; $lng = [double]$_.LONG
    "{`"type`":`"Feature`",`"geometry`":{`"type`":`"Point`",`"coordinates`":[$lng,$lat]},`"properties`":{`"id`":$($_.STRUC_ID)}}"
}
$drainsJson = "{`"type`":`"FeatureCollection`",`"features`":[" + ($drainsFeatures -join ",") + "]}"
$drainsJson | Out-File ".\data\drains.geojson" -Encoding utf8
Write-Host "Drains: $($drainsFeatures.Count) features"

# ── Storm Inlets ─────────────────────────────────────────────────────────────
# Expected columns: OBJECTID_1, OBJECTID, STRUC_ID, X_COORD, Y_COORD, ST_TYPE, Lat, Long
$inlets = Import-Csv "path\to\Inlets.csv"
$inletsFeatures = $inlets | Where-Object {
    [double]$_.Lat -ge $minLat -and [double]$_.Lat -le $maxLat -and
    [double]$_.Long -ge $minLng -and [double]$_.Long -le $maxLng
} | ForEach-Object {
    $lat = [double]$_.Lat; $lng = [double]$_.Long
    "{`"type`":`"Feature`",`"geometry`":{`"type`":`"Point`",`"coordinates`":[$lng,$lat]},`"properties`":{`"id`":$($_.STRUC_ID),`"type`":`"$($_.ST_TYPE)`"}}"
}
$inletsJson = "{`"type`":`"FeatureCollection`",`"features`":[" + ($inletsFeatures -join ",") + "]}"
$inletsJson | Out-File ".\data\inlets.geojson" -Encoding utf8
Write-Host "Inlets: $($inletsFeatures.Count) features"
```

Then update the layer count labels in the panel (`index.html`):

```html
<label for="chk-drains">Storm Drains <span style="color:#999">(1,529)</span></label>
<label for="chk-inlets">Storm Inlets <span style="color:#999">(736)</span></label>
```

The layers lazy-load on first toggle and are attributed automatically in the panel ("Filtered to project area · City of Oakland GIS Portal").

**Layer symbols** (colorblind-safe — distinct by shape and color):
- Storm Drains: blue circle ●  `#5B8DB8`
- Storm Inlets: green diamond ◆  `#3DAA77`

## Step 5 — Run locally first

The map uses `fetch()` to load JSON, so it won't work from `file://` — run a local server:

```bash
# Python
python -m http.server 8080

# or Node
npx serve .
```

Open **http://localhost:8080** and check:
- Photo markers appear at correct locations; clicking opens the lightbox
- Highlighted Photos panel shows correct images; mini-maps show correct locations; clicking the mini-map flies the main map there with an amber pulse
- Infrastructure layer checkboxes load and display correctly
- Title, client, and map center are correct
